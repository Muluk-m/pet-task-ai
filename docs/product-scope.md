# Product Scope

## Core Flow

1. Paste merchant rules or create a task manually.
2. Confirm required steps: Xiaohongshu note, Douyin post, ecommerce review, cashback.
3. Complete each step by submitting the required link or content.
4. Once all required steps are complete, the task moves from active to completed.

## Supporting Flows

- Manage copywriting materials.
- Manage pet image materials.
- Manage merchant review image materials.
- Show materials by upload time, newest first.
- Upload image materials from the phone camera or local album.
- Generate review/note content from task details, merchant rules, selected materials, style, and length.
