# Proposal: redesign-core-tasks

## Why

现有前端只是一个脚手架 demo：任务列表只显示标题，没有录入表单、看不到步骤、无法填笔记链接、无法确认返现，与产品主线（置换任务从录入到返现的全流程跟踪）差距巨大。本次按定稿的产品标准重做主线，为后续 PWA、AI 创建、好评生成三个 change 打好框架地基。

## What Changes

- 新增移动优先的底部 5 Tab 应用框架（首页 / 生成 / AI / 素材 / 我的），本 change 只实现首页与素材两个 Tab 的完整功能，其余 Tab 先落占位页
- 新增任务录入表单：标题、商家、商品、返现金额、截止日期、商家规则原文，四个步骤勾选项（小红书笔记 / 抖音帖子 / 电商好评 / 确认返现，返现默认勾选）
- 重做首页任务列表：进行中 / 已完成分组，卡片显示标题、步骤进度 x/y、返现金额、截止日期（临期/逾期高亮并置顶排序）；已完成任务置灰 + 删除线
- 新增任务详情页：展示商家规则原文（可折叠）、步骤清单；逐步骤完成（笔记类步骤填链接、好评步骤填链接或文本、返现步骤一键确认）；所有步骤完成后任务自动完成并移入已完成列表（沿用现有后端判定逻辑）
- 新增任务编辑与归档：创建后可修改标题/商家/商品/金额/截止日期/规则文本，可增删未完成的步骤；可归档任务（archived 状态已存在于表结构，补齐 API 与 UI）
- **BREAKING** `tasks` 表新增 `deadline` 字段，需要数据库迁移
- 后端补齐路由：任务详情（含步骤）、任务更新、任务归档、步骤增删、步骤撤销完成
- 现有素材管理功能迁入「素材」Tab，功能保持不变

## Capabilities

### New Capabilities

- `app-shell`: 移动优先的底部 Tab 导航框架，各 Tab 为独立页面，未实现的 Tab 显示占位页
- `task-management`: 置换任务的录入、列表展示、编辑、归档与截止日期跟踪
- `task-steps`: 任务步骤的生成、完成（含链接/文本佐证）、撤销与任务自动完成判定
- `material-management`: 三类素材（文案 / 宠物图片 / 商家评论图）的上传、浏览与删除（收编现有已实现功能，首次成文规格）

### Modified Capabilities

（无——当前 `openspec/specs/` 为空，所有能力均为首次成文）

## Impact

- `apps/web`：`src/main.tsx` 单文件应用将被页面化结构取代（路由、Tab 布局、任务/素材页面拆分），现有素材上传组件迁移复用
- `apps/worker`：`src/routes/tasks.ts` 扩展详情/更新/归档/步骤管理路由；保持 Hono 链式路由与 `AppType` 导出
- `packages/db`：`tasks` 表加 `deadline`；需 `pnpm db:generate` + 迁移
- `packages/shared`：新增/扩展 Zod schema（更新任务、步骤操作、截止日期）
- 不涉及：AI 网关接入（change ③）、PWA 与推送（change ②）、好评生成与统计（change ④）——但 Tab 框架须为它们预留占位
